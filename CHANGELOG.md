# Changelog

## 0.2.0 — 2026-09-29

Expanded the original 67-record collection to 930 records across 15 directions and 1872–2026: 163 annotated entries and 767 bibliography-only entries. Added classical radar, dynamics, rating and prediction work alongside engineering, climatology, warnings/social impacts, Chinese research and recent AI. Every entry carries a source link; 20 entries link verified code releases, collected in a separate paper/code index.

Recorded the dated Crossref/arXiv searches, exclusions, pending cases and retrieval limits. Completed 17 previously partial author lists, merged an early-online/final false-alarm paper duplicate, reconciled ASTRA/TorDet publication metadata and linked the Shakya paper to its CVPR workshop publication and Weather-R1 to the official ICASSP program.

Animated the original vortex artwork with flowing bands, sway and particles. Added pause, reduced-motion and offscreen behavior; introduced entry-detail filtering and direct code links. Fixed legacy DOI URL escaping and Windows repository-path comparison. Browser checks now use real local HTTP plus offline HTML and derive counts/routes from the catalog.

## 0.1.0-seed — 2026-09-29

Initial 67-record local starter: canonical data, 13 topic directions, bilingual annotated pages, BibTeX/CSV exports, research guides and an offline interactive observatory. This historical starter was prepared before authenticated access to the target remote was established.
